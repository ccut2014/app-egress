# AppEgress

**Анализ сетевых выходов приложений и управление маршрутизацией в Windows.**

[English](README.md) · [简体中文](README.zh-CN.md)

AppEgress объединяет TCP-соединения, локальные процессы, точки системного прокси и запросы маршрутов Windows. Режим наблюдения не меняет трафик; правила выбора адаптера включаются отдельно.

Поддерживаются светлая/тёмная темы, трей, английский, русский и упрощённый китайский.

## Границы наблюдения

- Запрос маршрута не доказывает передачу пакетов через выбранный VPN.
- Другие соединения локального процесса дают косвенные сведения, а не подтверждённую цепочку пересылки.
- Выход общего прокси и расход его трафика не определяются.
- Для UDP видны только локальная точка и PID; удалённый адрес и скорость не измеряются.
- Снимок соединений не является журналом команд или пакетов.
- Правила не включают автоматически дочерние процессы с другими именами.

## Запуск

Windows 10/11 x64 и права администратора. Вариант `win-x64-light.zip` требует .NET 8 Desktop Runtime x64; `win-x64-full.zip` включает среду выполнения.

После публикации загрузите архив из [Releases](https://github.com/ccut2014/app-egress/releases), распакуйте его, завершите прежний экземпляр через меню трея и запустите `AppEgress.exe`. Выберите наблюдение или адаптер и снимите паузу при необходимости.

Настройки сохраняются в `%APPDATA%\AppEgress`. При отсутствии нового файла читаются прежние настройки TrafikRuler, оригинал сохраняется. Подробнее: [совместимость и происхождение](UPSTREAM.md).

## Сборка

```powershell
./scripts/get-windivert.ps1
dotnet build AppEgress.sln -c Release
./scripts/package.ps1 -Version 1.1.0 -Variant Both
```

Скрипт упаковки не запускает тесты или приложение.
